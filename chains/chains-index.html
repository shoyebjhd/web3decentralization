How to Read the Scores

Each composite = 0.30 · infrastructure + 0.25 · capital + 0.25 · governance + 0.20 · software. Higher means more decentralized — harder for any party to coordinate enough independent actors to break the network. Run any chain live and export an audit report in the Terminal.
