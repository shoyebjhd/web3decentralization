## How to submit to an Awesome list (the standard way)

1. Fork the repo on GitHub.
2. Edit `README.md` — add our link under the most fitting header (e.g.
   "Learning", "Education", "Tools", or "Analysis").
3. Keep the line format: `- [Web3Decentralization](https://web3decentralization.com) - Free open-source Web3 learning hub + live chain-decentralization scores (CC0 data).`
4. PR with a short message: *"Add open-source crypto learning hub (courses, glossary, live Nakamoto-Coefficient scoring, CC0 data)"*.
