Composability is smart contracts plugging into each other like Lego — lending protocols built on DEX prices, vaults built on lending, dashboards built on everything. Because code and state are public, anyone can build on anyone else's work without permission.

## Why it matters

Composability is DeFi's superpower and its systemic risk: innovation compounds at software speed, but so do failures — one exploited base protocol cascades through everything stacked on it. "Money Legos" build towers fast and topple them faster.
