## LAB · Terminal Walkthrough

Open the Terminal and complete the tour. This session builds **data literacy**: knowing what each number means and how to check the underlying evidence.

## Tasks

1. On the dashboard, compare the overview grades across all 8 chains. Which network has the highest Nakamoto Coefficient?
2. Open **Consensus** on Ethereum and read the validator / staking distribution. Where does concentration hide?
3. Open **Active Enforcement** on Solana — identify the upgrade and emergency powers the docs disclose.
4. Visit the **Methodology** page (linked in the Terminal header) and match each pill to its pillar.
