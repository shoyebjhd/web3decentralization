## Deck for adversarial scenarios

Decentralization is not an abstract virtue — it is the property that keeps your transactions and assets **outside any single point of failure**.

- **Regulatory pressure** — which validators, miners, or entities can be pressured to filter specific addresses? The lower the coefficient the fewer phone calls it takes to censor.
- **Infrastructure capture** — if the top 3 validators are all hosted by the same cloud provider or legal entity, that is hidden concentration.
- **Upgrade forks** — if the core team can force an upgrade and the community cannot run a viable fork, "community" is a word, not a power.

Analysts with this lens can predict event outcomes before they happen — the market usually prices decentralization only after it breaks.

**Perspective:** You are learning a security framework that applies far beyond one token. The same questions scale across any governed system.
