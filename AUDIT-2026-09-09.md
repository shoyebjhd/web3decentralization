## 1. Availability — PASS (with one real caveat)

- **333/333 sitemap URLs return HTTP 200** at polite concurrency (≤2 parallel).
- **0 redirect chains**; canonicals self-consistent everywhere.
- **Burst tolerance:** 40/40 sequential requests → 200.

### Caveat 1 (confirmed, real): concurrency-triggered HTTP 500s

- With 8 parallel connections, ~60% of requests fail with **fast (~100 ms) HTTP 500s**; the same URLs return 200 sequentially seconds later.
- Signature matches the shared host's per-IP concurrency guard answering 500 instead of 429 — not a WordPress bug (nothing in the app stack explains 100 ms fatals), and not fixable with money-free server tuning on shared hosting.
- **Impact:** real visitors and Googlebot (gentle crawlers) are unaffected. Only parallel bulk-fetchers see fake "site down."
- **Rule going forward:** all automated crawling/monitoring of this site stays at ≤2 concurrent requests (audit tooling already does).
