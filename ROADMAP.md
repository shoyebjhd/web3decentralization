**beginners** — free forever, community-built, citation-grade data.

| Metric | Today | Target (Month 6) |
|--------|-------|------------------|
| Monthly organic visitors | ~0 | 10,000+ |
| GitHub stars | 0 | 1,000+ |
| Backlinks | 0 | 100+ |

| Contributors | 0 | 20+ |
