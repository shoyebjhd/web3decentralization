Block height is a block's number in the chain — genesis is 0 (or 1), and every
block increments by one. Halvings, upgrades, and unlocks are all scheduled by
height ("at block 840,000"), making it the blockchain's native clock.

## Why it matters

Height is how the network coordinates time without trusting anyone's watch:
"in 100 blocks" means the same thing to every node on Earth. Explorers,
halving countdowns, and vesting schedules all speak height — learn to read it
and on-chain timelines become legible.
