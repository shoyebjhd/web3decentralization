# Chain Audits

Per-chain decentralization audits, written for beginners and cross-linked to
the glossary and the interactive terminal.

Each audit follows the four-pillar methodology in
[`data/methodology.md`](../../data/methodology.md) and reports the composite
decentralization score.

## Format

```markdown
---
chain: btc
name: Bitcoin
consensus: Proof of Work
composite: 84.8
---

Intro for beginners... what this chain is and why decentralization matters.

## Four pillars
- Infrastructure: ...
- Capital: ...
- Governance: ...
- Software: ...

## Scorecard
See the interactive [scorecard](../../data/chains.csv).
```
