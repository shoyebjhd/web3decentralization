**The open-source learning hub for Web3 & crypto — from zero, for free.**

Free, community-built, citation-grade education about blockchain, crypto, and
decentralization. **Code is MIT. Learning content is CC-BY-4.0. Datasets are CC0.**

- 🖥️ **Interactive terminal** — live decentralization audits of 12+ L1 chains
  (Nakamoto Coefficient, four-pillar composite, stress tests, PDF export).
- 🎓 **Structured learning paths** — courses, quizzes, certificates, and
  interactive labs, built for absolute beginners.
- 📚 **Huge glossary** — hundreds of plain-English, cross-linked terms.
- 📊 **Open, reproducible data** — full methodology + raw datasets, so every
  score can be verified by anyone.

## What's in this repo

## Quickstart (terminal app)

```bash
git clone https://github.com/web3decentralization/web3decentralization.git
cd web3decentralization/terminal
npm install
npm run dev
```

> The terminal also runs live at
> [https://web3decentralization.com/terminal/](https://web3decentralization.com/terminal/).

## Contributing

We welcome contributors of all levels — no crypto experience required.

- **Write a lesson or glossary term** — easiest entry point, see
  [`content/README.md`](content/README.md).
- **Add or improve a chain audit** — see [`data/README.md`](data/README.md).
- **Fix a bug or add a feature to the terminal** — look for `good first issue`.

Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) before opening your first PR.
